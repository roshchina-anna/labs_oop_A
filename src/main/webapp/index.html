Создание табулированных функций

Введите точки вручную или выберите простую функцию, чтобы получить табулированное представление.

Главная страница-навигация

Выберите подходящий способ создания функции. Настройки фабрики автоматически применяются ко всем окнам.

Из таблицы точек

Постройте таблицу x/y и создайте табулированную функцию в один клик.

Из математической функции

Выберите встроенную функцию и задайте интервал с количеством точек.

Настройки фабрики

Укажите, какая фабрика должна использоваться при создании табулированных функций. Выбор применяется ко всем окнам и запросам.

Текущая фабрика ArrayTabulatedFunctionFactory

Массив подойдёт для компактного хранения и быстрого доступа по индексу, связный список — для частых вставок и удалений.

Изменение настроек моментально обновляет все окна создания функций.
